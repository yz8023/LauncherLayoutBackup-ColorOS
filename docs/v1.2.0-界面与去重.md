# v1.2.0：不再重复检查、功能去重、界面重排

## 1. 为什么以前每次进来都要检查一遍

旧逻辑里，`afterCreate()` 无条件跑一遍「Root / LSPosed / 备份目录」三项检查，只要有一项还没回执，
就继续盖着检查页。于是每次冷启动、每次从后台切回来被系统杀掉重建，都得重看一遍。

**现在的规则：**

| 情况 | 行为 |
|---|---|
| 首次使用（或升级后门禁规则版本变了） | 正常走一遍三项检查 |
| 以前通过过 | **直接进主界面**，后台静默给桌面发一次 `INFO` 复核 |
| 静默复核连续失败 2 次 | 才把检查页重新亮出来，并在日志里写明原因 |
| 想手动重查 | 设置 →「使用前检查」→ 重新走一遍 |

通过记录存在 `SharedPreferences("llb_app")` 的 `gate_passed_at` 里，
门禁规则变了就把 `GATE_VERSION` +1，老用户会自然重查一次。

## 2. 功能重复的地方，现在都只留一个入口

你之前遇到的「同一个功能两个地方都有，还得选一个」：

| 功能 | 以前出现在 | 现在只在 |
|---|---|---|
| 重启桌面 / 热重载 | 设置「热重载」+ 设置「Root 强制停止」+ 设置「唤醒桌面」+ 主页动作卡 + 主页「⋯」菜单 | **设置 → 桌面进程 →「重启桌面进程」**（失败自动改用 root 强停，不再让你选） |
| 检查连接 / 重新检测 | 主页「⋯ → 重新检测」+ 设置「测试连接」+ 主页状态卡 | **设置 → 桌面进程 →「检查连接」**；主页「⋯」里保留「重新检测桌面进程」（一次性维护动作） |
| 一键恢复最近备份 | 主页动作卡「一键恢复最近备份」+ 主页最近备份卡里的「恢复」+ 备份页每条「恢复」 | 主页最近备份卡「恢复这份」+ 备份页每条「恢复」（同一套确认弹窗） |
| 立刻备份 | 主页动作卡 | **主页「备份当前桌面布局」** |
| 备份路径 | 门禁第 3 项 + 主页首次强制弹窗 + 设置「备份路径」 | **门禁第 3 项**（首次）+ **设置 → 备份路径**（之后改） |
| 唤醒桌面 | 设置「桌面连接诊断」 | 并入「重启桌面进程」（它本来就是弱化版的重启） |

## 3. 界面重排

### 主页：从「一堆卡片」改成三层

```
桌面布局备份                              ⋯
只备份排版数据，不含 APK

[●] 已连接  ·  /storage/emulated/0/我的备份        5×8
    模块已注入桌面进程

立即备份
抓一份当前排版，通常只有几百 KB，几秒完成
[      备份当前桌面布局      ]

最近一次备份                          全部 →
3 分钟前                        [网格 5×8 ✓]
2026-11-27 10:12
[恢复这份]        [查看全部 4 份]

自动备份
每 7 天 · 上次 2026-11-20 08:00            >
```

- 状态从「一大块彩色卡片」压成**一行**（圆点 + 文案 + 网格胶囊），少占一屏；
- 主操作只有一个按钮，不再和「恢复」「重启」混在一张卡里；
- 「最近一次备份」用**相对时间当主标题**（3 分钟前），精确时间降为副行；
- 日志面板从 140dp 缩到 132dp，可在设置里彻底关掉。

### 备份页：每条一张卡，最新那条有淡绿底 + 「最新」胶囊

```
2026-11-27 10:12  [最新]                    [恢复]
3 分钟前 · 网格 5×8 ✓                  #1
```

不再用 `【最新备份】` 这种方括号文字当徽标（列表里全是括号，扫一眼分不出主次）。

### 设置页：分组更少、顺序更符合使用频率

自动备份 → 备份路径 → 保留策略 → 操作日志 → **桌面进程**（重启 / 检查）→ **使用前检查** → 关于。
「桌面连接诊断」整块删掉，并入「桌面进程」。

## 4. 仍然保留的两处「看起来重复」的设计（有意为之）

1. **门禁第 3 项** 和 **设置 → 备份路径** 都能设目录：前者是首次引导，只出现一次；
   后者是长期修改。不会同时出现，所以不用选。
2. **主页「恢复这份」** 和 **备份页每条「恢复」**：前者是最高频的「回滚到现在之前」，
   后者是挑历史版本。二者走同一套确认流程，行为一致。
